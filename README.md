# Страница услуги для Robokassa

Заведена 05.09.2026. Robokassa при создании магазина требует ссылку
на ресурс, где есть четыре вещи: контакты, описание и цена услуги,
реквизиты самозанятого, условия оказания и порядок возврата. Сайта у нас
не было — теперь есть одна страница, собранная из [`../mashina/oferta.md`](../mashina/oferta.md).

| Файл | Что это |
|---|---|
| [`index.html`](index.html) | сама страница: что за услуга, 1 200 ₽ за заявку и первая бесплатно, как работает, раздел «Публичная оферта» с условиями и возвратом, реквизиты Иакова, ссылка на бота |

Раздел назван «Публичная оферта» намеренно: Robokassa при активации
магазина требует, чтобы оферта была на сайте, и модератор ищет её
по заголовку. В разделе прямо сказано, чьи это условия и что оплата
означает согласие с ними.

## Куда выкладывать

На GitHub Pages: у Иакова есть аккаунт `iakovcencov-del`, репозиторий
`zayavki-remont`, публичный. Адрес после выкладки —
`https://iakovcencov-del.github.io/zayavki-remont/`. Его и вписывать
в форму Robokassa в поле «Ссылка на ваш ресурс».

Машина сама выложить не смогла: публикация в интернет — внешнее действие,
и оно остановлено до слова Иакова. Выкладка руками — три команды из папки
`sayt`:

    git init && git add index.html && git commit -m "Страница услуги"
    gh repo create zayavki-remont --public --source=. --push
    gh api -X POST repos/iakovcencov-del/zayavki-remont/pages -f "source[branch]=master" -f "source[path]=/"

Если ветка называется `main`, в третьей команде поставить `main`.

## Что на странице открыто всем

ИНН и почта Иакова. Для самозанятого, который продаёт услугу, это
обязательные реквизиты — без них Robokassa магазин не примет. Домашнего
адреса и телефона на странице нет.
